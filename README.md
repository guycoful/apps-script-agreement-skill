# apps-script-agreement

סקיל ל-Claude שבונה דף חתימה דיגיטלית בעברית על הסכם, ב-Google Apps Script. בלי שרת ובלי תשלום. הכל רץ בחשבון הגוגל שלך.

החותם רואה את ההסכם, ממלא פרטים וחותם באצבע או בעכבר. ואז:
- PDF חתום ו-PNG של החתימה נשמרים בתיקייה בדרייב.
- שורה נוספת לגיליון.
- החותם מקבל את ה-PDF במייל, ועותק מגיע אליך.

## התקנה
מעתיקים את התיקייה ל-`~/.claude/skills/apps-script-agreement`. ב-Claude Code הסקיל עולה כשמבקשים "הסכם לחתימה" או "דף חתימה".

## שימוש ידני
```bash
python3 build.py examples/config.json examples/agreement-body.html out
```
אחר כך פורסים את 4 הקבצים שב-`out` לפי `SKILL.md`, שלב 3.

## חשוב
הסקיל מייצר דף חתימה. הוא לא מחליף עורך דין. נוסח ההסכם באחריותך.
